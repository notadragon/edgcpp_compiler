## Rationale

P4451's main run test (the gnu_gcc fork's `p4451-run`): every kind of
terminating contract assertion -- pre, post with and without a result
name, `contract_assert`, members, templates, lambdas -- together with a
P3097 virtual function, P3098 captures, a P3099 message and a P4283
requires-clause, each enforced under a configured ignore and observe and a
P3595 configuration selecting observe.  Each runs under `--contracts_p4451`
alone, `--contracts_p3400` alone (`-p3400`) and both (`-both`), with the
same results.  It sits after the last paper it needs.

## Compile gap

None.  Pure test additions.
